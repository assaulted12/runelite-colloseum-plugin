# runelite-colloseum-plugin

A RuneLite plugin that automates the Colloseum completely.

## Features
- Colosseum region detection
- Nearby NPC target scanning
- Auto-eat logic for low health
- Prayer and combat helper hooks
- Auto-loot queue handling
- Status overlay

## Build

```bash
gradle build
```

## Local RuneLite development

For the proper local setup, see `DEVELOPMENT.md`.

## Notes
This project is structured as a cleaner, safer RuneLite plugin scaffold. It is designed to be extended with production gameplay logic in a real RuneLite development environment.
